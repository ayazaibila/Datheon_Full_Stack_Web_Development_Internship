# Datheon Full Stack Web Development Internship

A polished collection of four responsive web applications built with semantic HTML5, modern CSS, and vanilla JavaScript (ES6+).

## Applications

| Task | Application | Highlights |
| --- | --- | --- |
| 1 | [Personal Developer Portfolio](./Task%201/) | Aya Zaibila's profile, skills, credentials, projects, theme toggle, and contact links |
| 2 | [Task Manager](./Task%202/) | CRUD tasks, categories, due dates, filters, search, and localStorage persistence |
| 3 | [Weather Telemetry](./Task%203/) | Global city search, current conditions, five-day forecast, and resilient API states |
| 4 | [E-commerce Store](./Task%204/) | FakeStoreAPI catalog, search/filtering, persistent cart, totals, and checkout modal |

Open [index.html](./index.html) to browse all four experiences locally. The apps have no build step and can be deployed to GitHub Pages, Netlify, or Vercel.
